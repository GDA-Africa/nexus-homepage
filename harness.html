Precision Engineering

Built to verify, not just prompt.

By treating agents as engineering systems rather than magic boxes, the NEXUS Harness eliminates "vibe coding" and enforces strict contracts.

🔌
Cordis Plugin Kernel
Everything is an unprivileged, composable plugin. Dynamically mount, unmount, and patch behavior via cordis.yml and runtime profiles.
🧠
Native Brain Bridge
Hooks into agent/pre-step to inject ambient project context, exposing 16 native NEXUS tools directly to the runtime session.
⚡
Local Model Ergonomics
Zero-configuration local model support. A direct header bypass allows you to run Ollama and local models securely without API keys.
📜
Append-Only Telemetry
Every turn, step, model message, and tool result is an immutable SessionEvent. Model-visible means logged and verifiable.
