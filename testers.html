frequently asked questions

Tester Program Details

What is the expected time commitment?

Testing is completely asynchronous and self-paced. When a test flight is announced, you can spend as little as 5–10 minutes verifying a command on your setup, or integrate the pre-release into an active project.

Can I run preview builds alongside stable Nexus?

Yes. You can test preview builds locally via npx @nexus-framework/cli@next <command> without replacing your global npm installation, or switch back anytime with npm i -g @nexus-framework/cli@latest.

How do I submit feedback or bug reports?

You can run nexus doctor --severity=warn and share drift outputs, reply directly to the update email, or open a GitHub issue tagged with [tester-feedback].

Do I get recognition for testing?

Yes! Active testers who help uncover bugs, verify blueprints, or validate MCP tools are credited in release changelogs and GitHub release notes.
