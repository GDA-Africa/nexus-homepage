why mcp changes everything

Instructions get skipped.
Tool calls don't.

Deep dive: what MCP is & how NEXUS implements it →

Every AI-instructions file ever written says "read the docs first." Agents skip it. NEXUS v1.0 makes brain access structural instead of optional.

The old contract HOPE
  • "READ index.md before EVERY task": unverifiable
  • Whole files pasted into context, gotchas drown
  • Plans re-derived every session from scratch
  • Hand-edited frontmatter. one typo breaks the brain
The v1.0 contract STRUCTURE
  • nexus_wake, token + active plan + drift, one call
  • nexus_query_knowledge, the 2 relevant gotchas, not 200 lines
  • nexus_get_active_plan, resume exactly where work stopped
  • Validated writes, malformed brain state is impossible
the tool surface

16 tools. One brain.

Click a tool to see its shape. Reads return targeted data; writes go through the same parser the CLI uses, schema-validated, always.

nexus mcpNEW
The brain as a stdio MCP server. Registered automatically via generated .mcp.json.

      
nexus wake
Deterministic handshake token. Agents echo it, doctor flags sessions that skip it.

      
nexus sync
Repo sensors → Vital Signs block. Git, tests, files, packages. Idempotent, CI-safe.

      
nexus plan
Durable multi-step work in .nexus/plans/. Survives sessions, diffs cleanly.

      
nexus doctor
10 drift checks: stale docs, orphan plans, knowledge bloat, missed handshakes.

      
nexus brief
Status digest for humans, and for the brain-aware CI comment on every PR.

      
nexus consolidate
Memory hygiene. Rolls knowledge into a summary; append-only stays append-only.

      
nexus brain
Health dashboard + auto-invoke: the brain detects when it needs updating.

anatomy

    
Markdown is still the source of truth.

    
No database. No daemon. The MCP server is an interface over files you can read, diff, and version, agents and humans share the same brain.

    

      
.nexus/
├─ docs/           ← 8 structured docs (the brain)
│  ├─ index.md     ← status · backlog · vital signs
│  └─ knowledge.md ← append-only memory
├─ plans/          ← durable multi-step work
├─ skills/         ← how YOUR project does things
├─ state/          ← session tokens · sensor cache
└─ ai/             ← instructions for every agent
.mcp.json          ← auto-registers nexus-brain

      

        
Readable by anything
Cursor rules, AGENTS.md, CLAUDE.md, Copilot instructions, all generated, all pointing at the same brain.

        
Callable by MCP clients
npx -y @nexus-framework/cli mcp, spawned per client, exits with it.

        
Owned by you
Plain files in your repo. Eject anytime; your knowledge stays.
