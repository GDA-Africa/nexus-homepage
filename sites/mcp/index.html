how it works in everyday work

What is an MCP brain server, simply put?

MCP (Model Context Protocol) is an open standard that lets AI coding assistants connect to external tools. Instead of stuffing your whole repository into a giant prompt, NEXUS runs a lightweight brain server on your machine that gives Claude Code, Cursor, Codex, and Antigravity IDE 23 structured actions to look up what they need on demand.

📄
Markdown stays the source of truth

There is no hidden database or heavy background daemon. Your project memory lives in plain .nexus/ markdown files that you can read, version control with Git, and edit whenever you want.

⚡
Targeted answers, not file floods

When the assistant needs to know how you handle cookies, it gets back the exact 2-sentence lesson you recorded, rather than burning 4,000 tokens reading unrelated files.

🔒
Impossible to corrupt

When an AI tries to tick a plan step or record a note, the request runs through the NEXUS schema validator. It can never produce malformed files or accidentally wipe your notes.
