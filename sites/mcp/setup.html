Fastest Way: Automated Registration

Run this in any repo with NEXUS initialized. It auto-detects your installed editors and registers the MCP server configuration for you.

npx -y @nexus-framework/cli mcp
Place in repo root: .mcp.json 
{
  "mcpServers": {
    "nexus": {
      "command": "npx",
      "args": ["-y", "@nexus-framework/cli", "mcp"]
    }
  }
}

Next time you run Claude Code in this folder, NEXUS MCP tools wake automatically with zero extra flags.

Place in: .cursor/mcp.json 
{
  "mcpServers": {
    "nexus-brain": {
      "command": "npx",
      "args": ["-y", "@nexus-framework/cli", "mcp"]
    }
  }
}

Open Cursor Settings > Features > MCP to verify that the green light appears next to nexus-brain.
