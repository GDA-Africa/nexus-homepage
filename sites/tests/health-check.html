16 PRE-COMMIT SAFEGUARDS

Catching Unfinished Work
Before You Commit

Coding assistants often say "I'm done, everything works!" without actually running the test suite. NEXUS Doctor runs 16 automated sanity checks to verify proof, passing tests, and project memory alignment.

Rule D11: Provable Done

The "Did You Actually Run the Tests?" Check

No more unverified assumptions. When an AI agent marks a task complete, Doctor verifies that real test commands were executed and returned zero exit codes. If no tests were run, the commit is blocked.

Rule D09: Session Wake

The "Did You Read Project Memory?" Check

Ensures the AI assistant synced with your architecture and active plan before touching any files. Prevents blind edits that overwrite project conventions or repeat past mistakes.

Rules D01 - D04: Spec Sync

The "Are Docs Up to Date?" Check

Checks that your API contracts, data schemas, and implementation roadmap accurately reflect your code. If new routes or tables were created without updating the brain, you get flagged immediately.

Rules D14 - D16: Hygiene

The Clean Repository Check

Catches temporary scratch files, dangling console logs, loose test databases, and unformatted code before they ever make it into your git history.
