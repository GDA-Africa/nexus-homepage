Installation

Get NEXUS CLI installed and ready to use on your system

📋 Prerequisites
Before installing NEXUS CLI, ensure you have the following requirements met:
System Requirements:
• Node.js 20+ (required) • npm, yarn, or pnpm package manager • Git (recommended for version control) • Internet connection (for initial setup and updates)
Supported Platforms:
• macOS 10.15+ • Windows 10+ • Linux (Ubuntu 18.04+, CentOS 7+, etc.)
📦 Installation Methods
Choose your preferred package manager for installation:
npm (Recommended):
$ npm install -g @nexus-framework/cli
yarn:
$ yarn global add @nexus-framework/cli
pnpm:
$ pnpm add -g @nexus-framework/cli
✅ Verification
After installation, verify NEXUS CLI is properly installed:
Check Installation:
$ nexus --version nexus-cli/0.3.2 darwin-arm64 node-v20.19.5
Get Help:
$ nexus --help 🔮 NEXUS CLI v0.3.2 — AI-Native Development Framework Usage: nexus [options] [command]

Keep NEXUS CLI up to date with the latest features and improvements:
Check for Updates:
$ nexus update Checking for updates... Latest version: 0.3.2 Current version: 0.3.1 Updating to v0.3.2...
Manual Update:
$ npm update -g @nexus-framework/cli

nexus repair [path]

[path]

nexus init

Scaffold a new project from scratch with interactive prompts

📋 What It Does
The nexus init command creates a completely new project with:
Complete Project Structure:
• Framework-specific source code • TypeScript configuration • ESLint + Prettier setup • Package.json with real dependencies • Git configuration • Test infrastructure
AI Knowledge System:
• .nexus/docs/ (8 structured files) • .nexus/ai/instructions.md (master AI config) • Editor integration files (.cursorrules, .windsurfrules, etc.) • Agent Persona configuration
Skills System:
• Framework-matched core skills • Custom skills directory • Skills registry integration
🎯 Interactive Setup
Step-by-step guided configuration:
Strategy Questions:
1. What are you building? (Web, Mobile, Desktop, API, Monorepo) 2. How will your app handle data? (Local-only, Local-first, Cloud-first, Hybrid) 3. Which application patterns? (PWA, Offline-First, i18n, Theming, Real-time)
Technical Choices:
4. Which frontend framework? (Next.js, React+Vite, SvelteKit, Nuxt, Astro, Remix) 5. Testing framework? (Vitest, Jest, Playwright) 6. Package manager? (npm, yarn, pnpm)
AI Configuration:
7. Enable Skills System? (Yes/No) 8. What vibe should your AI have? (Professional, Friendly, Witty, Zen, Pirate) 9. How detailed should responses be? (Concise, Balanced, Detailed) 10. What should your AI call itself? (Custom name)
🚀 Quick Start
Get up and running in under 2 minutes:
Basic Usage:
$ nexus init my-app $ cd my-app $ npm run dev
With Project Name:
$ nexus init ecommerce-store $ cd ecommerce-store $ npm run dev

$ nexus init test-project --dry-run # Shows what would be created without actually creating files

nexus upgrade

Regenerate NEXUS files with latest templates, preserving user work

🔄 What It Does
The nexus upgrade command updates your project's NEXUS files with the latest templates while preserving your customizations:
Smart File Strategy:
• Reads YAML frontmatter to determine file status • Replaces template files with latest versions • Preserves populated files with your content • Never overwrites your custom work
Template Updates:
• Updates documentation templates • Refreshes AI instruction files • Upgrades framework-specific content • Enhances skills system templates
🎯 When to Use
Upgrade your NEXUS system when:
New NEXUS Version:
• NEXUS CLI releases new version • Template improvements available • New framework support added • Enhanced AI instructions released
Project Evolution:
• Framework version updates • New patterns or conventions adopted • Team workflow changes • New AI tools integrated
🚀 Quick Start
Upgrade your NEXUS system:
Basic Usage:
$ cd my-nexus-project $ nexus upgrade ✓ Checking current NEXUS version ✓ Analyzing existing files ✓ Downloading latest templates ✓ Applying smart file strategy ✓ Updating AI configurations ✓ Upgrade complete!
With Path:
$ nexus upgrade ./my-project $ cd my-project $ # NEXUS files updated!
⚙️ Smart File Strategy
How NEXUS decides what to update:
File Status Detection:
status: template → Replace with latest template status: populated → Preserve user content status: corrupted → Repair with latest template status: missing → Create new from template
YAML Frontmatter:
--- status: template version: 0.3.2 framework: nextjs --- # This file will be replaced on upgrade

1️⃣ Version Check

Current State Analysis:
• Checks .nexus/manifest.json for version • Identifies installed framework • Detects custom modifications • Validates file integrity

• Downloads latest template versions • Compares with current files • Identifies upgrade opportunities • Plans update strategy
2️⃣ File Analysis
Examines each NEXUS file:
Status Detection:
• Reads YAML frontmatter • Checks for user modifications • Validates file structure • Identifies corruption
Content Analysis:
• Compares with template versions • Detects custom content additions • Validates JSON/YAML syntax • Checks for missing required fields
3️⃣ Smart Updates
Applies updates intelligently:
Template Files:
• Replaces with latest versions • Updates framework-specific content • Enhances AI instructions • Improves documentation structure
Populated Files:
• Preserves all user content • Updates only metadata • Maintains custom modifications • Keeps business logic intact
4️⃣ Validation
Ensures upgrade success:
File Integrity:
• Validates all updated files • Checks YAML/JSON syntax • Verifies required fields • Tests AI instruction parsing
System Health:
• Confirms NEXUS system functionality • Tests editor integration files • Validates skills system • Checks manifest consistency

Project Migration:
• Moving projects between machines • Team member onboarding • Environment setup automation • CI/CD pipeline integration

• Sharing project context • Standardizing team environments • Onboarding automation • Knowledge transfer
