the problem

AI tools are powerful.
But they forget everything.

Every session, your AI agent starts from scratch. No memory of decisions. No understanding of conventions. No project context. Just you re-explaining everything. Again.

🧠
No Project Context
AI opens your project and asks "what's the architecture here?" — every single session. Cursor, Copilot, Windsurf — all of them.
With NEXUS → Agent reads project brain at startup. Full context. Always.
🔄
Wasted Decisions
You decided on a pattern. You explained why. Then the session ended. Next time, the agent proposes something completely different.
With NEXUS → knowledge.md captures every decision. Agents don't unlearn.
⚡
Inconsistent Code
No two sessions produce the same patterns. Components named differently. Imports structured differently. A codebase that drifts.
With NEXUS Skills → agents read how-to guides before every task.

the knowledge system

Eight living documents.
One project brain. Infinite AI context.

Every NEXUS project comes with a structured documentation system that AI agents parse automatically — covering vision through deployment.

🧠 index.md
Project Brain — status matrix, feature backlog, what to build next
📚 knowledge.md
Append-only memory — decisions, gotchas, patterns across sessions
01_vision.md
Product requirements, user stories, success metrics
02_architecture.md
System design, tech stack, data flow
03_data_contracts.md
Schemas, validation, relationships
04_api_contracts.md
Endpoints, interfaces, status codes
05_business_logic.md
Rules, algorithms, state machines
06_test_strategy.md
Coverage targets, test types, philosophy
07_implementation.md
Build order, file-by-file plan
08_deployment.md
Infrastructure, CI/CD, environment config
🧠 Project Brain
index.md is a live status matrix. AI agents check it before every task to understand what's done, what's in progress, and what should be built next. No more "what should I work on?"
📚 Progressive Knowledge Base
knowledge.md is append-only memory. Every architectural decision, every gotcha, every pattern gets logged here. Agents scan it before starting and write to it after discoveries.
🎭 Agent Persona
Configure your AI's tone, verbosity, and identity. When the agent reads the NEXUS instructions and calls itself "Nexus" — you know it's synced. It's your signal that context is loaded.
🔧 Multi-Tool Distribution
One knowledge system. Generated into .cursorrules, AGENTS.md, .windsurfrules, copilot-instructions.md, .clinerules, and context files for Gemini CLI and Ollama. Every agent reads the same truth.

NEXUS Skills — task-level AI knowledge.

NEXUS tells agents what you're building. Skills tell them how to build it. Before writing a single line, agents read the relevant skill file and follow your exact conventions.

◆
Core Skills
Generated at nexus init — framework-specific task guides for components, routing, testing, API routes.
◆
Custom Skills
Create project-specific conventions. Stored in .nexus/skills/custom/ — never overwritten by upgrades.
◆
Community Skills Registry
The official @nexus-framework/skills registry is live on npm — always current. Supabase, Stripe, Prisma and more. Fetches live so the registry stays up to date without a CLI republish.

The Alive Brain — Brain That
Detects Its Own Needs

Your project brain now has senses, memory, and voice. It watches your repo, detects drift, tracks work, and speaks to you at the right moments.

📡
nexus sync
Sensors capture real repo state — git history, test results, file ages, packages. Updates Vital Signs block in your brain.
📋
nexus plan
Multi-step work tracking in `.nexus/plans/`. Create, approve, start, tick, note, and complete plans. Your brain orchestrates work between sessions.
🏥
nexus doctor
10 modular drift checks. Flags stale docs, orphaned plans, missing knowledge, version mismatches. Keeps your brain honest.
📢
nexus brief
30-line human-readable digest. Status, health, next steps, alerts. Share with your team or send to your agent.
🧠
Auto-Invoke Layer
Brain detects when it needs updating and prompts you. No more "when should I run this?" — your brain tells you.
💾
.nexus/plans/
Persisted, version-controlled work tracking. Every plan is a markdown file in your repo. Full history, team visibility.
